# Project archive

Historical project material is preserved here so the repository root and public
documentation stay focused on the current product.

| Directory | Contents |
| --- | --- |
| `planning/` | Original handoff notes, duplicate drafts, earlier README, and error example |
| `submission/` | Hackathon submission copy, media guide, and thumbnail |
| `audits/` | Earlier audit exports and report data |
| `legacy/` | Original chatbot prototype, retained for reference |

These files describe earlier stages and may contain outdated commands, scores, dates,
or links. They are not the current operating instructions. Use the root README and
`docs/` for supported behavior. The archive is not included in the documentation site.
